# contact-chain-cert

**承诺：把多刚体链的 4 点接触流形约简从「取前 4 个顶点」变成带精确有理证书的约束选择——在 6 条 24 体链、138 个接触界面、6 轮扰动共 828 个流形上，上层合质心严格落在支撑四边形内的比例 100%（138/138），朴素 `truncate4` 基线只有 47.83%（66/138），且面积/质心/包含判定全部用 BigInt 分数精确算出，无 epsilon。**

`Upstream: none`（原创；无上游仓库）

## 怎么跑

```bash
node tools/gen-sample.mjs     # 生成 data/scenarios.json + data/reference.json
node bench/verify.mjs         # 23 条断言，全部打印实际值
node bench/bench.mjs          # 7 次采样 + 冷启动，写 bench/result.json
node baseline/truncate4.mjs   # 朴素基线：47.83% 包含率
python3 -m http.server 4173    # 打开 http://localhost:4173
```

页面用固定版本 three@0.169.0 的 importmap；拖场景/扰动轮滑块，浏览器用同一个 `src/core.mjs` 现场复算，并把拓扑签名与 node 生成的 `data/reference.json` 对账（round 0 显示 `node/browser match`）。

## 证据（全部来自 `bench/result.json` 与本机真实运行）

| 指标 | 本实现 | 对照基线 |
|---|---|---|
| 合质心包含率（138 界面） | **100.00%（138/138，精确严格内点）** | `truncate4` **47.83%（66/138）** |
| 最小稳定裕度（长度单位） | **0.698564**（中位 0.880207） | 基线在 72/138 个流形上质心落到四边形外，裕度为负 |
| 特征 ID 跨 6 轮扰动稳定性 | **Jaccard 均值 0.999420**（690 对界面，最小 0.6） | 基线无持久 ID，无法 warm-start |
| 6 轮扰动下包含率 | **690/690 = 100%** | — |
| 面积/质心精确性 | 46/46 轴对齐闭式面积逐位相等；138/138 质心与独立扇形三角化 oracle 逐位相等；Pick 定理在 D=48 与 D=240 的格点上 2/2 逐位相等 | float 管线无精确证书 |
| 尺度不变性 | 1e-6 / 1e-3 / 1 / 1e3 / 1e6 五档共享同一 feature+subset 拓扑签名，面积精确按 k² 缩放 | — |
| 全流程耗时（138 界面） | 冷启动 479.260 ms；7 样本中位 **462.407 ms**、p95 467.804、stddev 2.521、relStddev **0.54%**；**3350.77 µs/流形** | `truncate4` 中位 **60.463 ms（438.1 µs/流形）**，但 52.17% 流形不含质心 |

精确性有代价：本实现比截断基线慢约 7.6×，换来的是精确包含判定、持久 feature ID 与可复算的面积/质心。`bench/result.json` 是墙钟产物，每次重跑会重写；采样数与冷启动都单独记录。

## 核心做了什么

1. **精确有理几何**：所有长度是 `{n,d}` BigInt 分数（d>0、既约）。偏航只取勾股对 (1,0)、(3/5,4/5)、(5/13,12/13)，保证旋转后坐标仍是有理数，因此接触多边形、面积、质心、包含判定没有浮点误差。
2. **接触多边形**：Sutherland–Hodgman 用精确分数裁剪上体底面与下体顶面的投影，每个输出顶点带**来源 feature key**（原始角点，或「subject 边 × clipper 边」的有序对）。
3. **4 点约简是约束优化**：在 ≤8 个顶点的凸多边形上穷举全部 4 子集（≤70 个），只接受**严格包含上层合质心**的四边形，再取最小边裕度最大者（并列时比精确面积、再比索引字典序）。无可行子集时如实返回 `contains=false`。
4. **座位干涉解析**：原始链每个界面有 2–8‰ 的有理干涉量；`settle` 逐级精确抬升后，138/138 个界面的间隙**恰好为 0**，断言同时记录原始干涉全部为负。
5. **warm-start 特征稳定性**：对每条链做 6 轮确定性有理扰动（±1/3000、±1/2500），比较相邻轮流形 feature ID 的 Jaccard。

## 已知限制（重要）

- **没有动力学**：不做冲量/LCP 求解，不模拟滑动或碰撞响应；证书只覆盖「静止、已就位」链的流形选择与几何正确性。摩擦锥、接触力分配均不在范围内。
- 支撑质心只按体积加权（密度均匀），不含载荷或外部力。
- 约简枚举假设接触多边形是 ≤8 顶点的凸多边形；本语料由两个有理旋转矩形相交得到，满足该前提；一般网格接触不适用。
- **绝对量纲**：稳定裕度以世界长度单位报告（本语料 0.698–1.055），不是无量纲比值；跨尺度测试证明拓扑与「面积按 k²」精确等变，但裕度数值本身随尺度线性缩放。
- 选择阶段的最大裕度比较用 `Math.sqrt` 把精确的边长平方转成 float 排序，并用 **`1e-12`（绝对 float 阈值）** 判定两个候选裕度是否并列；**包含判定、面积、质心、Jaccard 全部是精确分数**，该阈值只影响候选排序，不影响证书真假。
- 尺度不变性断言在 `chain-0` 上做（1e-6…1e6），其余 5 条链只在单位尺度跑；固定种子语料可随时扩到全链复验。
- **公平性披露**：仓库里的 `baseline/fps4.mjs`（最远点采样）在这份语料上也能 138/138 包含质心，只是最小裕度略低（`node baseline/fps4.mjs` 实测中位 **0.879376** vs 本实现 **0.880207**）——**本轮不宣称优于 FPS-4**；相对 `truncate4` 的 47.83% 才有明确差距。
- 语料是合成的 6 条链（轴对齐与两种勾股偏航），不是真实 glTF 资产；`data/` 由固定种子脚本生成，两次运行字节一致。
- 浏览器只验证了静态服务 200 与 importmap 存在；无头环境不做真实 WebGL 截图（按方向书禁止浏览器自动化）。

## 本轮创新

**B 档**：此前台账里的接触流形（`contactforge-lab`）是「单盒 × 整数高度场 → 4 点流形」，只保证几何非穿透；本轮首次把 **4 点约简本身写成带精确有理证书的约束优化**——在 8 顶点接触多边形上穷举 4 子集并要求上层合质心严格在内，同时把 **feature ID 跨扰动轮的 Jaccard 稳定性**和 **Pick 定理格点面积**做成可现场复算的指标。与 `contactforge` 的差别不是换主题：那边选 4 点靠规则、没有包含证书、没有跨轮 ID 指标、没有多体链；这边 52.17% 的流形在朴素截断下会丢质心，而本实现 138/138 精确保住。
